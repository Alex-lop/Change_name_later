# Stack

Stay inside this stack. Do not introduce a new framework, database, or test runner.

- Backend: Python 3.11+, FastAPI, DuckDB, Pydantic v2, httpx. Package manager is `uv`. Tests are pytest plus Hypothesis, run from `backend/` with `uv run pytest -q`.
- Frontend: React 18 and Vite. Plain JSX in `frontend/src/`. No TypeScript, no component library.
- Patients: synthetic only. Generated by `python -m dryrun.synthea`. Never use real patient data.
- Parses: cached in `backend/data/parse_cache.json`, keyed by the exact criterion sentence. The demo must not depend on a live LLM call.
- ClinicalTrials.gov API v2 is the only external trial source.

The LLM translates a criterion sentence into a structured rule. It never sees patient rows and it never returns a verdict.
